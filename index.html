Como o modelo funciona: intensidade de 0 a 100 = xG (30 pts) + Momentum (25 pts) + Escanteios (20 pts) + Chutes/Chutes no alvo (15 pts) + Ataques perigosos (10 pts). Quando um indicador não está disponível na fonte de dados (ex.: xG = N/D), a pontuação é reequilibrada proporcionalmente entre os indicadores disponíveis — nenhum número é inventado. Somente partidas com ≥ 70/100 e dados suficientes entram na lista de oportunidades.

⚠️ Scanner de oportunidades — os dados vêm em tempo real e podem conter atraso. Isto não é recomendação de aposta e nada é garantido.

Build · a página é estática — os dados ao vivo vêm direto da API a cada ciclo, nada é gravado no GitHub Pages. Se o número do build aqui não mudar após um push, é cache do navegador (recarregue com Ctrl+Shift+R).
